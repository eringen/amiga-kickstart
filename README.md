# Amiga boot screen

Open `index.html` directly in a browser. No server, build step, or network
connection is required. Zdog 1.1.3 is included in `vendor/` under the MIT license.

The canvas uses Zdog models at a fixed 640 × 496 resolution and scales to fit
the viewport.

## GitHub Pages

In the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
The included workflow publishes the site on pushes to `main` and can also be
started manually from the Actions tab.

Site URL after deployment: https://eringen.github.io/amiga-kickstart/
